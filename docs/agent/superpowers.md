## Duty

**before** any response or action — including clarifying questions, exploring
the codebase, and checking files.

If there is even a 1% chance a skill applies, read the **current** skill file
and follow it. Do not rely on memory. Skills evolve.

Then announce "Using [skill] to [purpose]" and follow the skill exactly. If it
has a checklist, create a todo per item.

## Who

This applies to **coordinators and workers**, not only coding agents. A plugin
note that a dispatched subagent may ignore Superpowers does **not** apply on
this project.

“Go faster / skip process” is **not** an implicit skip.
